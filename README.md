# 🎬 CineTrail - A Movie & TV Show Recommendation App

CineTrail is a sleek and responsive React web app that allows users to search, discover, and explore movies and TV shows based on custom queries or mood-based recommendations. It fetches real-time data from the TMDB (The Movie Database) API and presents results with intuitive UI, pagination, and dark mode support.
## 🔥 Features

- 🔍 Search for movies and TV shows
- 🌈 Get recommendations based on mood (e.g., happy, sad, romantic, action, thriller)
- 🎭 Browse by type (Movies or Series)
- ⭐ View ratings, posters, and release dates
- 📱 Fully responsive design
- 🌙 Dark mode theme
- ⏳ Loading shimmer effect
- 🔁 Pagination for browsing more results

---

## 🛠 Tech Stack

- **Frontend**: React, Material-UI, CSS
- **API**: [TMDB API](https://www.themoviedb.org/documentation/api)
- **Deployment**: Render
